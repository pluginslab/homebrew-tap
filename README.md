# Pluginslab Homebrew tap

```bash
brew tap pluginslab/tap
brew install --cask glossa      # Whisper dictation for the Mac: https://github.com/pluginslab/glossa
```

Or in one go: `brew install --cask pluginslab/tap/glossa`.

Casks here point at the signed, notarized builds on each project's GitHub Releases
page; the checksum in each cask is the one `release.sh` printed for that DMG.
